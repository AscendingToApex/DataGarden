# 🌱 DataGarden

**Where data blossoms and insights take root.**

A curated collection of beginner-friendly **reference guides**, **cheat sheets**, and **templates** for data analysts of every level and aspiring data scientists — spanning the whole journey from spreadsheets and SQL to statistics, visualization, and machine learning.

Every guide follows the same shape: a table of contents, worked examples, `Note`/`Pro Tip` callouts, a glossary, and links out to authoritative docs. Each opens with a **level** (🟢 Beginner · 🟡 Intermediate) and its **prerequisites**.

---

## 🧭 How to Use This Repo

- **Browse by topic** — each folder below has a `README` landing page listing its guides in reading order.
- **Follow a learning path** — see the paths below if you're not sure where to start.
- **Grab a cheat sheet** — most topics include quick-reference PDFs in their `cheat-sheets/` folder.
- **Reuse a template** — starter files live in each topic's `templates/` folder.

Each topic folder is organized the same way: `guides/` (the reference guides), `cheat-sheets/` (quick-reference PDFs), and `templates/` (reusable starters).

## 🗺️ Learning Paths

**🌱 New to data (entry-level analyst)**  
Data Literacy → Spreadsheets → SQL → Visualization → Statistics

**📈 Analyst leveling up**  
Python → Data Wrangling → SQL (dialect portability) → Statistics → Visualization (dashboards & storytelling)

**🤖 Analyst → entry-level Data Scientist**  
Python → Data Wrangling → Statistics → Machine Learning → Forecasting → Deep Learning Intro

**🛠️ Foundations (useful anytime)**  
Tools & IDEs → Git & GitHub → Command Line
